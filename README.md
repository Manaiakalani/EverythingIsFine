# Everything Is Fine

A single page of lo-fi fire. A cat sits in a flame border under the caption "~ lo-fi flaming vibes ~", with heat shimmer, embers, film grain, and a VHS overlay.

Click the cat, or press Space, for a burst of fire.

Open `index.html` in a browser. There is no build.

- `index.html` is the page
- `effects.css` is the fire, grain, and VHS styling
- `lofi-vibes.js` is the click, hover, and keyboard behavior
- `2092sn.jpg` is the cat
